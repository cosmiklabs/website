# HPLX website

The independent product website for HPLX: an editor for *Amnesia: The Dark
Descent* custom stories, with playtesting built in. Built as a small static site,
with no package dependencies, framework or third-party services.

The combined website build serves this site under `/hplx/`. Run `npm run check` and `npm run dev` at the website repository root. The build uses the shared brand snapshot.

## Content and presentation

The site leads with the editor/playtest loop and useful story-creation tools.
It explains current development status and offers a real email conversation,
without claiming downloads, beta access or a subscription service.

The room plan is original schematic artwork. It is clearly labeled as an
illustration, never as HPLX output or a screenshot. No original game content is
included. The optional diagram controls highlight steps of the same workflow;
all explanations and questions remain available without JavaScript.

Claims and limitations are recorded in [content evidence](docs/content-evidence.md).
Brand and product facts are distinct: visual identity approval does not announce
a release, compatibility, pricing for the original game, or other products.

## Brand provenance

The shared snapshot supplies Glimmer, Spectral, and the HPLX overrides. The build loads them over the Cosmik baseline and includes the applicable notices.
